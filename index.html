      ⚙ GitHub Sync Setup

      This app saves data to a GitHub Gist so it syncs across all your devices for free. Follow these steps once:

      1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
      2. Click Generate new token, give it a name, check the gist scope only, and generate.
      3. Copy the token and paste it below. It is stored only in your browser (never sent anywhere except GitHub).

      Your Gist ID will be created automatically on first sync and saved locally. On a new device, enter the same token and the same Gist ID will be found automatically.
